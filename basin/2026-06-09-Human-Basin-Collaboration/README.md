# Human Basin Collaboration

This basin records the decision to make collaboration in this repository
human-centered and basin-based, rather than modeled primarily on ordinary
GitHub contribution flow.

## Purpose

The basin uses a real exchange as the first example:

1. a TODO assessment proposed a revised priority order;
2. the user accepted the direction but asked whether the answer itself could
   become the example basin;
3. this basin preserves that exchange as proposition, implementation, validation,
   interpretation, and promotion.

## Local Stance

This is intentionally lighter than the full companion protocol format from
[reflexive-coherence-agentic-protocol](https://github.com/urosj/reflexive-coherence-agentic-protocol).
It follows the concepts: proposition, implementation, validation, interpretation,
promotion, tension, returnability, and refinement subbasins.

The goal is to make the collaboration geometry readable to humans without
requiring full protocol compliance for small public contributions.
