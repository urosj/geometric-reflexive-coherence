# Naturalization of Becoming

## When Probed Capacity Becomes Native Regime Expression

**Date:** 2026-05-28

Copyright © 2026 Uroš Jovanovič, CC BY-SA 4.0.

## Abstract

Classification of Becoming asks what a system expressed. Interrogation of
Becoming asks what bounded question reveals the boundary that made the
expression possible. But a further question is needed before cultivation can
be claimed: when does a capacity first revealed by support, probe, scaffold, or
special condition become available through the system's own structure?

This paper names that bridge **Naturalization of Becoming**.

Naturalization is the process by which a property first expressed under
external support, bounded intervention, or selected conditions becomes
available through the system's own regime. A capacity is naturalized when the
system no longer needs the original probe to express the property, because the
function of the probe has been internalized as a regime condition, boundary
structure, recurrent process, support ecology, or self-generated event.

The central distinction is:

```text
probe-exposed capacity
  is not the same as
native regime expression
```

This keeps Naturalization distinct from Cultivation. Naturalization asks the
narrow bridge question: when does supported capacity become native
availability? Cultivation asks the broader practice question: how does an
observer participate in the whole cycle of orientation, observation,
classification, probing, withdrawal, naturalization, and integration without
forcing closure or optimizing proxies?

The paper also records a correction learned from the Paper-30 arc. It is not
enough to classify every observation or to translate every probe into a
nearby optimization target. A classification must become reusable and
generative before it should organize naturalization. Otherwise the observer
falls into the proxy-localization trap: the missing function is replaced by a
measurable proxy, and the search begins to optimize the proxy rather than
cultivate the function.

The central claim is:

```text
Naturalization of Becoming asks when a system can generate, through its own
regime, the function that the observer previously supplied from outside.
```

## 1. Why Naturalization Is Needed

The sequence of the becoming papers now has five layers:

```text
Language of Becoming:
  describe the regimes.

Classification of Becoming:
  name what appears.

Interrogation of Becoming:
  ask bounded questions.

Naturalization of Becoming:
  ask when a probed capacity becomes endogenous.

Cultivation of Becoming:
  develop through the full cycle.
```

Naturalization is therefore not the full developmental method. It is the
specific test inside the developmental method where supported expression must
show whether it can become endogenous. Cultivation contains naturalization, but
naturalization supplies the standard that prevents cultivation from becoming a
series of well-designed supports.

Without naturalization, the sequence skips from asking questions to cultivating
conditions too quickly. A probe can expose a real capacity, but the capacity
may still depend on the probe. A support scaffold can let a system express a
property, but the system may not have grown the structure that makes that
property available. A special environment can make a regime appear stable, but
the stability may disappear when the environment is withdrawn.

This is not a failure of the probe. It is the reason the probe was useful. It
revealed a boundary:

```text
the system can express X if support Y is supplied
```

Naturalization asks the next question:

```text
what would have to change inside the system so that Y no longer needs to be
supplied from outside?
```

In phenomenological language, this is the movement from:

```text
I can enter this state when conditions hold me
```

to:

```text
my system has grown the geometry that makes this state available from within
```

In technical language, it is the movement from support-dependent expression to
endogenous support generation.

## 2. The Naturalization Gap

The naturalization gap is the distance between a property the observer can make
visible and a property the system can produce through its own organization.

It can be written simply:

```text
probe-exposed capacity:
  the system expresses a property when an intervention supplies support,
  timing, coupling, localization, boundary, readout, or scaffold

native regime expression:
  the system expresses the same class because its own regime generates the
  relevant preconditions
```

The gap matters because many results are meaningful without being native.

A bounded probe may show that an event can become a consequence. That does not
mean the unprobed system creates the consequence. A feedback layer may show
that split telemetry can change geometry. That does not mean split execution
itself changes geometry. A supportive condition may reveal calm, insight,
cooperation, polarity, or recovery. That does not mean the system can generate
the condition under ordinary perturbation.

The naturalization gap preserves the value of the probe while blocking the
overclaim.

The correct reading is:

```text
The probe revealed a possible property.
Now identify the function supplied by the probe.
Then ask what endogenous condition could supply that function.
```

## 3. Naturalization Is Not Support Translation

The easiest mistake is to translate the probe support directly into a designed
native support and then optimize until the effect appears. That is not
naturalization. It is support translation.

Support translation says:

```text
the probe supplied local polarity
therefore design geometry that resembles local polarity

the probe supplied coupling
therefore add a coupling-like native surface

the probe supplied a boundary
therefore hard-code a boundary-like condition
```

This may be useful as an experiment. It can test whether the function has been
understood. But it does not by itself prove that the system has naturalized the
capacity.

Naturalization asks a stronger question:

```text
does the system generate the function of the support through its own regime?
```

The object is not the support shape. The object is the function the support
performed.

For example:

```text
external support function:
  localize consequence near an event surface

endogenous function sought:
  a regime-generated support relation that makes event surfaces locally
  consequential without explicit intervention
```

The exact support may differ. A naturalized system need not copy the probe. It
must supply an equivalent role.

## 4. The Naturalization Loop

The practical loop is:

```text
1. Expose:
   use a bounded probe to reveal a possible property.

2. Classify:
   name exactly what appeared and what support produced it.

3. Decompose:
   identify which function was supplied by the probe:
     energy,
     localization,
     timing,
     polarity,
     boundary,
     coupling,
     recurrence,
     readback,
     scaffold,
     coordination.

4. Test class value:
   decide whether the classification is only a local observation tag or a
   reusable/generative becoming class.

5. Weaken:
   reduce the probe while preserving the property if possible.

6. Substitute:
   replace external support with endogenous regime features.

7. Recur:
   test whether the system can regenerate the precondition through its own
   evolution.

8. Confirm:
   compare against no-probe, weak-probe, shifted-probe, active-control, local
   null, and wrong-support cases.

9. Reclassify:
   label the result as probe-dependent, partially naturalized, native,
   generic, source-specific, support-dependent, or unresolved.
```

The fourth step is the correction added by the later P30 evidence. Without it,
naturalization can chase every classified miss. The method must first ask
whether the class is worth naturalizing.

## 5. The Naturalization Ladder

Naturalization needs its own ladder because support-dependence has many
intermediate forms:

```text
N0 probe-dependent expression:
  property appears only under explicit probe.

N1 probe-weakened expression:
  property survives weaker support but not removal.

N2 regime-assisted expression:
  property appears when background regime conditions are adjusted, but still
  requires a trigger.

N3 endogenous precondition formation:
  the system forms the missing support structure before the explicit probe.

N4 native expression:
  the property appears without the original probe under declared conditions.

N5 recurrent native expression:
  the system repeatedly regenerates the property or its preconditions.

N6 self-interrogating regime:
  the system produces internal structures functionally equivalent to the
  original probe.
```

The final rung should be read carefully. "Self-interrogating" does not require
agency or inner language. In a technical system it means:

```text
the system endogenously generates the boundary condition, perturbation class,
or support function that the observer previously supplied from outside
```

In human or phenomenological language it can be described more simply:

```text
the system has learned to ask the question of itself
```

But the technical definition must remain primary.

## 6. The Classification Value Gate

Naturalization depends on classification, but classification alone is not
enough.

The P30 Step 47 sequence showed the productive version of classification. The
desired endpoint was too coarse, so the system's expressed properties were
decomposed into score competence, gate competence, overlap coupling, body
lineage, shape, and position. This made the next experiment more meaningful.
The classification created a property-composition question.

Later P30 arcs showed the failure mode. The work continued to produce accurate
labels, but some labels became increasingly local:

```text
latest obstacle named
latest proxy refined
next repair suggested
```

That can become a methodological local minimum.

Naturalization therefore uses the same value gate as the updated
Classification of Becoming:

```text
T0 observation tag:
  faithful local label; useful for audit only

T1 reusable class:
  travels beyond one local setup or clarifies a contrast

T2 generative class:
  produces a new question, boundary, or rung

T3 operational class:
  defines a method, probe, intervention, or measurement rule

T4 theoretical class:
  changes how the core proposition should be understood
```

Only T1 or higher should organize a naturalization branch. T0 tags may still be
recorded, but they should not drive repeated optimization unless they expose a
more general function.

The practical question is:

```text
Does this classification create a reusable generator question?
Or does it only make the next local repair more precise?
```

## 7. The Proxy-Localization Trap

Naturalization can fail even when classification and probing are disciplined.

The failure mode is:

```text
1. A probe reveals a missing boundary.
2. The boundary is translated into measurable proxies.
3. The proxies become the new endpoint.
4. The search optimizes local variants around those proxies.
5. The original question is replaced:

   from:
     can the system generate the function naturally?

   to:
     can we make this proxy pass?
```

This is the **proxy-localization trap**.

It is not the same as sloppy experimentation. Each local step can be reasonable.
The trap is that the operationalization becomes the object. The observer begins
to cultivate the sign rather than the function.

The guard is:

```text
Do not cultivate the proxy.
Cultivate the function.
```

Expanded:

```text
A proxy is useful only while it remains a sign of the system supplying the
function that was previously supplied from outside.

When optimization improves the proxy without increasing withdrawal, source
specificity, recurrence, broader regime validity, or native expression, the
branch has become local optimization and must be reclassified.
```

Every naturalization branch should keep these five objects separate:

```text
original probe function:
  what the probe supplied

endogenous function sought:
  what the system would have to generate for itself

proxy metric:
  provisional measurable sign of that function

local optimization target:
  the tunable operational surface currently being adjusted

native regime expression:
  the property appearing because the regime generated the needed function
```

If these collapse into one object, naturalization has become endpoint
optimization again.

## 8. Generator, Not Winner

Naturalization searches should not ask first:

```text
which row passes?
```

They should ask:

```text
what generator condition makes the class available?
```

This is the difference between finding a winner and finding a source of
capacity.

A winner may be one seed, one geometry, one timing, one hardware-sensitive
surface, or one narrow local combination. It can be useful evidence. But it
does not yet explain how the system makes the capacity available.

A generator condition is broader. It says what kind of support ecology,
balance, boundary, history, or phase relation must be present for the property
to arise. It may not immediately pass the endpoint. Its value is that it
explains why some rows become capable and others do not.

The naturalization question is therefore:

```text
Can the system form the generator condition without the observer supplying the
probe?
```

This is why historical integration matters. A reusable classifier should be
backcast into old evidence before launching another large search. If the class
reorganizes older failures, it has become a lens. If it only names the latest
neighborhood, it should remain local.

## 9. Withdrawal and Support

Naturalization must not mean repeating the probe until the system depends on
it. That would be conditioning or dependency, not naturalization.

The central test is withdrawal:

```text
If support is weakened, does the capacity remain?
If support is removed, does the system generate an equivalent structure?
If the result disappears, it was probe-dependent.
If the result persists only under a special environment, it is
  regime-assisted.
If it recurs through the system's own dynamics, it is naturalized.
```

Withdrawal should not be cruel, abrupt, or careless. Some capacities need
scaffolded emergence. But without some form of weakening, substitution, or
support audit, the observer cannot distinguish development from dependence.

The rule is:

```text
Support is allowed.
Hidden support is not.
```

Naturalization does not despise support. It asks what the support was doing and
whether the system can increasingly supply that function for itself.

## 10. Relation to Cultivation

Naturalization is narrower than cultivation.

Cultivation describes the whole developmental discipline:

```text
orient
observe
classify
probe
withdraw
naturalize
integrate
```

Naturalization focuses on one central transition:

```text
externally supported property
  ->
internally available capacity
```

Cultivation needs naturalization because otherwise it can become a cycle of
well-designed scaffolds. The system expresses richer states, but only because
the observer keeps arranging the conditions. That may be useful, but it is not
yet development of native capacity.

Naturalization asks whether the system has grown the relevant geometry.

## 11. General Examples

In a PDE-RC simulation:

```text
A probe creates local polarity or split consequence.
Naturalization asks whether the field/regime can generate the same support
function without explicit probe support.
```

In human development:

```text
A person can remain calm when another person regulates the room.
Naturalization asks how calm becomes available under ordinary perturbation.
```

In creative work:

```text
Insight appears only under crisis or deadline.
Naturalization asks how the conditions for insight can be generated without
requiring collapse.
```

In AI:

```text
A scaffolded prompt produces reasoning.
Naturalization asks whether the system has the capacity, or whether the prompt
supplied the reasoning structure.
```

In social systems:

```text
A group cooperates when an external authority holds the boundary.
Naturalization asks whether the group can generate stable boundary and role
conditions itself.
```

The same distinction holds across domains:

```text
supported expression is real,
but naturalized capacity is a stronger claim.
```

## 12. Central Claim

Naturalization of Becoming can be stated in one sentence:

```text
Naturalization asks when a capacity first revealed by a bounded probe becomes
part of the system's own way of organizing, so that the system no longer needs
the observer to supply the question from outside.
```

The longer form is:

In nonlinear, self-describing, computationally irreducible systems, a property
may first appear only under external support, special conditions, or bounded
intervention. That appearance is meaningful but not yet native. The
naturalization task is to identify the function supplied by support, test
whether the classification is reusable and generative, weaken or withdraw the
support, and determine whether the system can generate the relevant
preconditions through its own regime.

Naturalization therefore guards against two errors:

```text
underclaim:
  dismissing a supported capacity as artificial and therefore meaningless

overclaim:
  treating a supported capacity as native expression
```

The correct middle path is:

```text
the support revealed a possible capacity;
now ask whether the system can learn to supply the function of that support
for itself
```

## Conclusion

Classification of Becoming prevents failed predictions from erasing what
appeared. Interrogation of Becoming prevents successful probes from pretending
to be proof. Naturalization of Becoming prevents probe-supported expression
from being mistaken for native capacity.

The Paper-30 correction adds another guard: do not let classification and
naturalization collapse into local proxy optimization. A class must be
reusable, generative, and coherence-preserving before it should organize the
next developmental arc. A proxy must remain a sign of a function, not become
the function itself.

The movement is therefore:

```text
observe what appeared
classify it carefully
ask what boundary made it possible
identify what support supplied
seek the endogenous generator of that support function
withdraw, compare, and reclassify
```

When this succeeds, the system has not merely been made to express a property.
It has become the kind of system for which that property can arise.
