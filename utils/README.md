# Utilities

This directory contains helper scripts for converting the repository Markdown
papers into PDF documents.

The scripts are currently in a basic, crude working state. They were kept
because they capture the current PDF-generation workflow, but they still need
polishing before they should be treated as stable tooling. Expect hard-coded
paths, limited error handling, and assumptions inherited from the paper-drafting
process.

## Contents

- `ROM-pdf/` contains the older PDF conversion workflow and supporting files.
- `core-pdf/` contains scripts for processing the current core papers.

Use these utilities as working helpers rather than as a documented build system.
