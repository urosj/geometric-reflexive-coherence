# Quick Start

This repository is a papers-first introduction to **Geometric Reflexive
Coherence**. It is meant for readers who want to understand the theory before
going into the implementation repositories.

## The Short Version

Geometric Reflexive Coherence studies self-defined, self-referential, dynamic
systems. The central object is a coherence field whose state induces geometry,
whose geometry guides flux, and whose flux updates the field:

```text
C -> K[C] -> g[K] -> J[C,g] -> continuity -> C
```

This loop is the core idea. Identity is a stable basin of coherence. Memory is
persistent geometry. Choice is the local experience of a collapse whose outcome
cannot be predicted by any part smaller than the whole evolving system.

## How To Read Claims

This archive contains theory, experiments, interpretation, and implementation
notes. Read claims at the strength stated in each paper:

- **definition** means a proposed formal object or rule;
- **observation** means an experimental or conceptual pattern recorded from a
  run or investigation;
- **supported** means supported under the controls described in that paper;
- **blocked** means the paper identifies a missing condition or failed path;
- **future work** means the construction is not yet implemented or validated.

The repository is an open laboratory. It is meant to make the reasoning and
experimental path visible enough that others can inspect, repeat, criticize, or
extend it.
